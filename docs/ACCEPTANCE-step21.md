## 实现与来源

- Python `MonitoringService`在FastAPI lifespan构造和退出，默认每60秒检查；规则默认关闭。
  共用原`Database`、`CapabilityRegistry`、`ProviderService`、日历、自选、组合、研究、报告、论点服务。
  没有第二套TS内核、数据适配器或健康状态；React只显示返回值和编辑草稿。
- 八类提醒：价格高于/低于、新新闻、财报临近、评级变化、股息临近、持仓权重及组合回撤。
  价格严格超过/低于阈值，市场关闭不触发，状态缺失明确失败；组合数据不足或来源模式不符不估算。
  金额/比例使用原始Decimal，币种分别计算；组合回撤是本规则观测到的本币资产峰值变化，包含现金/导入影响，
  不等同于收益率序列或调整资金流后的投资表现。首次评级仅建基线，新闻须比成功游标新且不在未来。
  财报规则引用已保存同模式/提供商的日历快照，保留snapshot/event/read身份；过去预告不证明已经发生。
- 五类固定自动化：工作日自选复查、组合每日简报、每周论点复审、财报前/后研究入口。
  自选复查用已有quote链按原始价格相对昨收绝对变化至少5%产生实质变化入口，`all`可通知所有完成的复查。
  组合简报仅聚合当前保存快照；每周复审列出已有论点，不自动判断投资影响。
  财报前/后由明确事件时间/发生状态驱动；自动化不默认开始模型报告。
  财报前/后规则可勾选默认关闭的“触发后自动采集”，仅限指定股票；其他入口显式点击“开始一次采集”。
  两者共用原`ResearchService.start`及同一领取记录；不会隐式调用报告模型，也不补发失败/不确定的动作。
- `0016_monitoring`新增规则、执行和一次采集动作三表；创建UUID重放同规则，不同内容同UUID报冲突。
  同一规则/计划时刻或检查分钟有数据库唯一约束；游标、证据身份和冷却持久化，去重身份不按历史展示数量淘汰。
  每日计划按IANA时区和ISO星期，默认工作日16:30、周复审周日09:00；DST不存在时刻跳过，重复小时仅取第一次。
  规则最多100条、启用最多20条；能力读取2.5秒协调期限、最多4个未结束执行器，迟到结果不能写触发事实。
  逐规则失败保留明确代码及成功来源，失败不生成通知/研究。退出取消调度及读取；不扩为系统服务或常驻任务。
- 新启动发现到期计划记录`skipped/APPLICATION_CLOSED`及错过区间，不补跑。
  运行中崩溃遗留执行记`interrupted`；领取后未确认通知记`uncertain`，旧待投递通知记`suppressed`。
  关闭期间条件提醒未轮询，不推断或编造期间行情；重新打开只评估实际重新读取的来源。
- Electron主进程轮询待通知，Python在SQLite事务中先领取，随后由Electron `Notification`显示和回写结果。
  `shown`须收到原生`show`回执；原生失败/不支持/展示超时可见，未把领取当显示成功。
  采用最多一次展示尝试：领取后崩溃、回执失败不会再发，但可能丢失通知；不承诺跨SQLite和操作系统的恰好一次交付。
  通知点击只显示/聚焦已有窗口，不启动模型；renderer不能提交任意通知文案。
- 一次采集动作在调用原研究服务前持久化领取；同一触发/股票重复点击、并发和重启返回同一动作。
  崩溃中的动作记`uncertain`，不会自动重新研究；失败动作保留原因，不靠重复轮询重试消费。
  触发提交后、动作领取前退出可能没有派发；首版同样不补跑，不能声称可靠恰好一次任务交付。
- Today按所选时区聚合组合、自选、提醒、事件、研究、报告及尚未人工复审的论点版本。
  每项有来源类型/身份/状态/理由，模式和提供商在可用时保留；事件跨多个快照只展示较新身份。
  `brief`记录每日日期、来源计数及待关注数量，是已有事实的确定性简报，不是模型生成投资判断。
  刷新、切时区和重启读取已有服务，不重新采集或创建研究。规则与执行详情保留可核对事实。
  页面懒加载，旧响应不能覆盖新时区/卸载后的页面；600px窗口无横向溢出。
- 固定Folio概念参考、7份文件SHA256和授权边界见[SOURCES-step21.json](SOURCES-step21.json)。
  本步没有原样导入上游代码或资源；既有技能/许可声明保留。不把局部MIT扩为全仓授权。
  工程参考：[Electron Notification](https://www.electronjs.org/docs/latest/api/notification)、
  [Python zoneinfo](https://docs.python.org/3.12/library/zoneinfo.html)。
