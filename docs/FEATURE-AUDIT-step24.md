## 未闭环链路的本步修复

1. 开发目录Python、迁移、技能路径改为冻结资源路径；数据库落入用户数据目录，不写安装目录。
2. 冻结后 sys.executable 为 bootloader，SDK worker 使用独立参数入口；不再把后端可执行文件当解释器并重新启动服务。

4. 打包评测需要的10份源码/迁移与原生SDK/时区/证书；安装版评测运行实际迁移沙箱，不能以仅文件存在代替可用。
5. 安装版忽略开发页面、解释器、DB及历史夹具环境覆盖；提供显式独立数据目录参数，生产单实例及所属进程清理；开发回归路径保留。
6. NSIS 明确保留卸载后数据，来源/数据说明随包提供；创建的产物只进入 ignored build/release。
