## 用户操作（待填写）

```cmd
cd /d "D:\folio\research-trail"
call start-dev.cmd
```

1. 进入“设置与诊断”，五类最初未配置。模型保存配置，保持“测试前要求已保存凭证”不勾选，点“测试假连接”，模型假成功而其他类未配置。
2. 行情选择假失败、保存后测试；账户选择假失效、保存后测试，核对状态不同且模型不变。
3. 模型更改名称并保存，原成功失效；重测再成功。勾选要求凭证后无凭证应失效。只输入自造测试占位值（不是真实API密钥），保存后密码框清空，重测可假成功；删除凭证失效、删除配置回到未配置。
4. 保存本机显示名和研究偏好，关闭并重启同一数据库，核对配置/资料保持。系统凭证按本机用户与数据库命名空间保存，不随数据库移动。
5. 读取/导出脱敏诊断，核对各独立状态，搜索你自造的测试占位值、资料和地址，均不应出现；系统保存对话框可取消。结束时删除自己创建的测试配置/凭证。

## 边界

所有成功都是确定性假连接测试；无真实LLM/行情/账户请求，设置不切换既有Agent或模拟数据。技能完整注册/扫描、真实运行时、多模型工具循环及真实数据接入留待相应步骤。

只支持Windows Credential Manager，无明文/环境变量降级存储。诊断只输出白名单状态，不能当作完整安全认证。系统条目清理失败或提交后进程崩溃可能留下孤立系统凭证；应用拒绝明文降级，普通Python字符串不承诺内存完全擦除。其他OS、真实服务、安装包、系统凭证跨机器迁移、备份恢复/故障注入的全部崩溃点未验证。
