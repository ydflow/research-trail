## 正式 v1.0.0 具体缺口

1. 无独立干净 Windows 环境。现有 Windows11 开发机实际安装与移除开发工具 PATH 测试不能替代全新操作系统、无源代码/开发工具安装证明。首次 GUI 引导、杀毒/SmartScreen、非 ASCII 用户名、低权限及离线重装仍需独立验收。
2. 当前安装包未签名，仍用默认 Electron 图标。签名信任及产品视觉资源未验收；未请求购买/导入签名凭证。
3. 完整基线缺常驻三栏/跨页面资产页签、思考级别、会话完整 Markdown、真实模型 A/B 比较/完整质量评测、报告概率置信度及其 Diff/真实校准。研迹自己的12案例不冒充上游86案例。基于安全/架构规则的模拟空态和 Python替代 Pi 是明确设计差异，需确认是否接受完整交付口径。
4. 真实行情、账户、日历、LLM 质量、外部追踪、本包真实连接重连与权限不足场景未执行。部分基线能力依赖未随包分发的用户 Longbridge CLI；当前能诚实显示未配置/缺依赖，不宣称已具备全部真实服务。
5. Longbridge wheel 的版本对应许可证及原生依赖分发声明尚需进一步核实；既有官方两份许可证和边界 NOTICE 已随包保留，但不将仓库 main 文本冒充该 wheel 的独立认证。
6. 本机升级覆盖原创0017→0018；更早版本、多次安装升级、损坏库恢复、降级、长时调度/压力/真实投资样本未验收。卸载默认用户目录保留配置已固定，实测采用独立自定义数据目录，无系统凭证新增/删除，不声明已测真实用户凭证清除。
